# sql-reference
SQL concepts and query patterns built for learning, practice, and quick revision
----------------------------------------------------------
SQL = Structured Query Language

SQL is a language used to communicate with and manage databases.
It allows us to store, retrieve, modify, and manage data efficiently.

Database = A place where data is stored
SQL = The language used to communicate with the database
--------------------------------------------------------
SQL is mainly used to:
Read data → SELECT
Add data → INSERT
Update data → UPDATE
Delete data → DELETE
Create tables → CREATE TABLE
Filter data → WHERE
Sort data → ORDER BY
Combine tables → JOIN
Group and calculate data → GROUP BY, COUNT(), SUM(), etc...
